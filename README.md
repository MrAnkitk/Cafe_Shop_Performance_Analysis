# Café Shop Performance Analysis | Excel

## Project Overview

This project focuses on analysing café sales and operational data using Microsoft Excel. The objective was to transform raw data into meaningful business insights through data cleaning, KPI analysis, PivotTables, calculated measures, and an interactive dashboard.

The project also includes a business analysis report and a PowerPoint presentation to communicate key findings and recommendations.

## Dataset

The dataset contains café transaction data used to analyse sales, product performance, customer traffic, and store operations.

Key areas analysed:
- Sales and transaction volume
- Product categories and product sizes
- Hourly and weekday sales patterns
- Store location performance
- Average bill and average order size

## Tools & Technologies

- **Microsoft Excel** — Data cleaning, analysis, and reporting
- **PivotTables & PivotCharts** — KPI calculations and summarisation
- **Excel Measures** — Calculated business metrics
- **Slicers** — Interactive dashboard filtering
- **Microsoft PowerPoint** — Presentation of findings and recommendations

## Project Workflow

1. **Data Loading:** Imported the raw café dataset into Excel for analysis.
2. **Data Cleaning:** Checked data quality, reviewed missing values, and prepared the dataset for analysis.
3. **KPI Analysis:** Used PivotTables to calculate and analyse key performance indicators.
4. **Measure Creation:** Created calculated measures to evaluate business performance.
5. **Dashboard Development:** Built an interactive Excel dashboard with KPI cards, charts, and slicers.
6. **Business Reporting:** Prepared a report highlighting key findings, business insights, and recommendations.
7. **Presentation:** Created a PowerPoint presentation to communicate the analysis and results.

## Dashboard

The interactive dashboard provides an overview of café performance through the following KPIs and visualisations:

**Key Performance Indicators**
- Total Sales
- Total Quantity Sold
- Total Footfall
- Average Bill
- Average Order Size

**Dashboard Analysis**
- Quantity and order trends by hour
- Product-size distribution
- Top products by sales
- Sales distribution by product category
- Orders by weekday
- Performance comparison across store locations

**Interactive Features:** Day and month slicers allow users to filter the dashboard and explore performance across different periods.

## Key Results & Business Insights

- **Total Sales:** $698,812.33
- **Total Quantity Sold:** 214,470
- **Reported Footfall:** 149,116
- **Average Bill:** $4.69
- **Average Order Size:** 1.44 items

Key findings from the analysis:

- Coffee and tea were the leading product categories, contributing approximately 66.7% of total sales.
- Hourly demand peaked at 10 AM, highlighting the importance of morning staffing and inventory planning.
- Friday recorded the highest order count among the weekdays shown in the analysis.
- The three store locations showed relatively similar sales performance, allowing for further comparison of operational efficiency.
- The analysis identified opportunities to improve product availability, staff scheduling, and data quality.

## Business Recommendations

- Align staffing levels with peak-hour demand.
- Maintain sufficient inventory for high-performing product categories.
- Evaluate product bundles to encourage higher average order values.
- Compare store performance using sales, transactions, and operating costs.
- Improve data completeness and consistency for more reliable reporting.
